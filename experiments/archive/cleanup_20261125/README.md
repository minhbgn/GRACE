# Superseded experiment helpers

These are the original one-off report compilers, live throughput diagnostics,
scheduler-recovery helpers and overlapping launchers removed from active
experiment directories on 2026-11-25. Their exact bytes are preserved; paths
inside them describe the original layout. They are historical source evidence,
not maintained launch commands.

Use [the consolidated command reference](../../README.md),
`evaluation/runners/evaluate.py` for dispatch/comparison, and
`evaluation/audits/compile_results.py` for CPU matrix/timing reports.
Pinned numerical runners remain in `evaluation/` at their original hashes.
`results/migration_20261125.json` records moved source/artifact checksums.

Original report/readme text is preserved separately under
`results/report_sources/` and summarized in `experiments/REPORT.md`.
