# Surviving cached datasets

These links expose surviving Hugging Face snapshots without downloading data or duplicating the shared cache. They are live links, not independent backups. The Arrow cache is linked at ../recovery/available_dataset_cache. See ../recovery/dataset_inventory.json for available snapshot files.

Cached subsets may differ from the deleted benchmark populations. They have not been installed as substitutes into the original evaluation/data paths. Training subsets and video assets have not been recovered here.
